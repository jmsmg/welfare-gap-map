# 지자체 복지사업 공통 분류표 (LLM 사업 정리 시범, AI 1단계)

지자체 복지사업 글(사업명, 요약, 지원 대상, 선정 기준, 지원 내용)만 읽고 아래 항목을 채운다.
글에 없는 것은 짐작하지 않는다. 글로 판단이 안 되면 빈 값으로 두고 `메모` 에 까닭을 짧게 적는다.

입력: `out/llm/input_<n>.jsonl`, 한 줄에 사업 하나.
  `id`, `시군`, `servNm`(사업명), `servDgst`(요약), `sprtTrgtCn`(지원 대상), `slctCritCn`(선정 기준), `alwServCn`(지원 내용)
출력: `out/llm/labels_<n>.jsonl`, 입력과 같은 순서로 한 줄에 사업 하나, 아래 키를 모두 넣은 JSON.

## 항목

| 키 | 값 | 판단 기준 |
|----|----|-----------|
| `id` | 입력의 id 그대로 | |
| `대상특성` | 목록. 고를 수 있는 값: `저소득`, `장애인`, `보훈대상자`, `한부모·조손`, `다문화·탈북민`, `다자녀`. 없으면 `[]` | 받을 자격을 그 집단으로 좁히거나 그 집단을 따로 우대할 때만 넣는다. 저소득은 기초생활수급자, 차상위, 기준중위소득 몇 % 이하 같은 소득 조건이 있을 때. 다자녀는 자녀 수 조건(둘째, 셋째 이상 등)이 있을 때. 모든 주민이 받는 사업은 `[]` |
| `장애_세부` | `발달장애`, `장애일반`, `""` | `대상특성` 에 장애인이 있을 때만. 지적, 자폐성, 발달장애라고 적혀 있으면 `발달장애`, 아니면 `장애일반`. 장애인이 없으면 `""` |
| `생애주기` | 목록. 고를 수 있는 값: `영유아`(0~5세), `아동`(6~12세), `청소년`(13~18세), `청년`(19~39세), `중장년`(40~64세), `노년`(65세 이상), `임신·출산`. 나이 제한이 없으면 `[]` | 나이나 학년, 임신, 출산 조건이 있을 때 그 구간에 걸치는 값을 모두 넣는다. 예: 초등학생은 `아동`, 중고등학생은 `청소년`, 출산 가정 지원은 `임신·출산`, 만 65세 이상은 `노년`. 부모가 받지만 자녀 나이가 조건이면 자녀의 생애주기를 넣는다 |
| `분야` | 하나. `생계·소득`, `출산·양육`, `돌봄`, `건강·의료`, `주거`, `교육`, `일자리`, `문화·여가`, `이동·교통`, `기타` | 지원이 주로 채우는 욕구. 생계비, 수당, 생필품, 공과금은 생계·소득. 출산장려금, 양육비, 아이 용품은 출산·양육. 돌봄 서비스, 주간보호, 활동지원, 가사 지원은 돌봄. 의료비, 검진, 치료, 재활은 건강·의료. 장례, 안전, 행정 감면 등 나머지는 기타 |
| `제공방식` | 목록. `현금`, `현물`, `바우처·지역화폐`, `서비스`, `감면`, `융자`, `시설입소`, `기타` | 받는 사람에게 무엇이 가는가. 계좌 입금, 장려금, 수당은 현금. 물품 지급이나 대여는 현물. 이용권, 바우처 카드, 지역화폐, 상품권은 바우처·지역화폐. 교육, 상담, 돌봄, 프로그램 운영은 서비스. 요금이나 세금 깎아 주기는 감면. 대출, 이자 지원은 융자(이자만 대신 내 주면 현금). 여럿이면 모두 |
| `소득기준` | `있음`, `없음` | 소득이나 재산, 수급 자격 조건이 있으면 있음 |
| `소득기준_내용` | 짧은 글, 없으면 `""` | 예: `기준중위소득 50% 이하`, `기초생활수급자, 차상위계층` |
| `나이_최소` | 정수 또는 `null` | 받는 사람(또는 조건이 되는 자녀)의 나이 하한. 학년이면 나이로 바꾼다(초등 1학년 7세, 고3 18세). 없으면 null |
| `나이_최대` | 정수 또는 `null` | 나이 상한. 없으면 null |
| `거주요건` | `있음`, `없음` | 그 시군에 몇 개월, 몇 년 이상 주민등록 같은 거주 기간 조건이 있으면 있음. 단순히 그 시군 주민이면 된다는 것만 있으면 없음 |
| `발달장애인_낮활동` | `true`, `false` | 발달장애인(또는 발달장애인을 포함한 장애인)이 낮 시간을 보내는 활동, 주간 돌봄, 주간보호, 방과후 돌봄, 평생교육 프로그램을 제공하거나 그 비용을 대 주면 true |
| `메모` | 짧은 글, 없으면 `""` | 판단이 애매했던 점만 (30자 안쪽) |

## 출력 예

```json
{"id": "WLF00000131", "대상특성": [], "장애_세부": "", "생애주기": [], "분야": "기타", "제공방식": ["현금"], "소득기준": "없음", "소득기준_내용": "", "나이_최소": null, "나이_최대": null, "거주요건": "있음", "발달장애인_낮활동": false, "메모": "장례 비용 지원"}
```
