# 복지 공백 지도: 시범 분석

시군구마다 복지 수요(대상자 수)와 공급(사업, 시설, 제공기관)을 공개 사회보장 데이터로 맞대어 빈 곳을 찾고, 인구와 수급 구조가 닮은 '쌍둥이 시군구'와 견주어 공백 점수를 매기는 분석입니다. 2026 사회보장 데이터를 활용한 AI 혁신 아이디어 경진대회(한국사회보장정보원, 대구가톨릭대학교)에 낸 제안서 '복지 공백 지도'의 근거 자료이고, 제안서의 숫자와 그림은 모두 이 저장소의 `out/` 에서 나왔습니다. 혼자 만들었습니다 (조성곤).

## 공개 범위

- `scripts/` 코드(MIT), `out/` 결과 표·그림·LLM 분류 결과, `data/raw/` 에 받은 공개 자료(아래 자료 표의 이용허락 조건을 따름).
- 받은 자료에서 개인을 가리키는 칸(기관장명, 대표자명, 기관 전화번호, 이메일)은 `scripts/scrub_personal.py` 로 지우고 올렸습니다. 분석에는 쓰지 않는 칸입니다. 기관 이름, 주소, 사업 내용 같은 공개 정보는 그대로입니다.
- 공공데이터포털 API 키는 `.env` 에만 두고 올리지 않습니다 (`.env.example` 참고).

---

2026 사회보장 데이터를 활용한 AI 혁신 아이디어 경진대회에 낼 제안서의 시범 분석입니다. 시군구마다 복지 수요(대상자 수)와 공급(사업, 시설, 제공기관)을 맞대어 빈 곳을 찾습니다. 시범 지역은 경북 22개 시군이고, 장애인 복지(발달장애인 주간활동, 방과후활동)부터 봅니다.

## 실행

모든 스크립트는 표준 라이브러리만 씁니다. 받은 원본은 `data/raw/` 에 그대로 두고, 결과는 `out/` 에 씁니다.

```sh
# 1. 받기
python3 -I scripts/fetch_datagokr.py 15062448 15063014 15072489 15075530 15097972 15127872 3075166 15083323 15116392  # 공공데이터포털 파일 (저장소에 이미 들어 있음)
python3 -I scripts/fetch_api.py check                                   # 키가 세 API 에 다 듣는지 (키 필요)
python3 -I scripts/fetch_api.py provider                                # 사회서비스 전자바우처 발달장애인지원 제공기관 (두 번 부름)
python3 -I scripts/fetch_api.py fclt-kinds && python3 -I scripts/fetch_api.py fclt --word 장애인   # 사회복지시설 (키 필요)
python3 -I scripts/fetch_lcgv.py list                                   # 지자체복지서비스 목록 (키 필요)
python3 -I scripts/fetch_lcgv.py detail --sido 경상북도                  # 경북 사업 상세 289건 (하루 1,000회 한도)

# 2. 공백 분석
python3 -I scripts/bokjiro.py      # 복지로 연령별 등록장애인 요약 (data/raw/bokjiro/ 에 사용자가 받은 파일)
python3 -I scripts/providers.py    # 제공기관 정리 기록 (뺀 행, 합친 행, API 와 옛 파일 비교, 주간이용시설)
python3 -I scripts/gb_dev_gap.py   # 경북 시군의 발달장애인 수 대비 제공기관 → out/tables/gb_dev_gap.csv
python3 -I scripts/twins.py        # 쌍둥이 시군구 → out/tables/twins.csv, twins_features.csv
python3 -I scripts/gap_twins.py    # 쌍둥이와 견준 공백 점수 → out/tables/gap_twins.csv (twins.py 다음에)
python3 -I scripts/figures.py      # 제안서 그림 3개 → out/fig/*.png (Chrome 헤드리스로 그림)

# 3. LLM 사업 정리 시범 (AI 1단계)
python3 -I scripts/lcgv_prepare.py # LLM 입력(글만) out/llm/input_*.jsonl 과 숨길 복지로 분류 out/llm/bokjiro_tags.csv
#   LLM 이 scripts/llm_taxonomy.md 의 분류표대로 input_<n>.jsonl 을 읽고 out/llm/labels_<n>.jsonl 을 쓴다
#   (2026-11-08 시범은 Claude 에이전트 셋이 묶음 하나씩, 복지로 분류를 보지 않고 분류)
python3 -I scripts/lcgv_eval.py    # 복지로 분류와 일치율, 시군별 장애인 대상 사업, 검수 표본 30건

# 공개 전 (받은 자료의 개인 식별 칸 지우기, 여러 번 돌려도 같음)
python3 -I scripts/scrub_personal.py
```

API 키는 `.env` 의 `DATA_GO_KR_KEY` (공공데이터포털 일반 인증키, Decoding). `.env` 는 커밋하지 않습니다. API 를 부르는 공통 함수는 `scripts/api.py` 이고, 키는 화면과 오류 글에서 지웁니다. 하루 한도나 키 오류가 오면 멈춥니다.

## 제공기관 정리 규칙 (scripts/providers.py)

API 자료(쓰는 값): 기관 아이디(providerId)로 셉니다. 한 기관이 여러 시군구에 등록돼 있으면 시군구마다 셉니다(주간활동, 방과후활동 기관 가운데 전국 3건). 사업유형이 '발달장애인 주간활동서비스' 나 '청소년 발달장애인 방과후활동서비스' 인 기관이 제공기관이고, '최중증발달장애인 통합돌봄서비스' 만 하는 기관은 따로 셉니다. 모르는 사업유형이 나오면 멈춥니다.

옛 파일 두 가지(비교용, API 자료가 없을 때는 쓰는 값):

1. 관공서(시청, 군청, 구청, 도청, 행정복지센터) 행은 뺍니다. 2025-09 자료에 34행 있습니다 (예: 영주시청, 안동시청 노인장애인복지과). '시청소년' 처럼 이름에 '청소년' 이 든 기관은 남깁니다.
2. 시군구 칸에 주소가 들어간 행은 시도와 시군구까지만 씁니다.
3. 시도만 적힌 행은 기관 이름에 든 시군구 이름(예: '경산시지부')으로 시군구를 정하고, 못 정하면 뺍니다 (1행).
